# Browse & Search

Origin is currently released in early beta. You can create repos, push and pull with git, mirror from GitHub, browse and search code, open and merge pull requests, and share with your Cursor team.

Please submit any and all feedback to [hi@cursor.com](mailto:hi@cursor.com) to help us make the product better.

Open a repository at [cursor.com/codebase](https://cursor.com/codebase) to browse files, search code, and inspect commit history on the **Code** tab.

## Folders and files

On **Code**, browse directories and open files in the tree. Switch branches from the branch control in the header. The green **Code** button opens HTTPS and Origin CLI clone setup.

![Origin repository Code tab with file tree and file contents](/docs-static/images/origin/browse-files.png)

## Search

Use **Go to file** (shortcut `T`) or the search field in the repository header to find files and code matches.

![Origin repository search for files and code](/docs-static/images/origin/browse-search.png)

## Branch history and commits

From **Code**, open commit history for the current branch. Select a commit to see its message, metadata, and changed files. Use the branch control to move between branches before opening history.

## Related

The repository header also has **Pull requests** and **Settings** tabs alongside **Code**:

- [Pull requests](https://cursor.com/docs/origin/pull-requests.md) - open, review, and merge pull requests
- [Settings](https://cursor.com/docs/origin/settings.md) - sync status, access, rules and protections, and apps
